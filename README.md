# 🏦 Loan Approval System - AI Powered

An intelligent Loan Approval Prediction System using **XGBoost** with role-based dashboards for Admin, Employee, and Customer.

Live Demo: _coming soon_

### 🚀 Features
- **ML Model:** XGBoost Classifier with 85%+ accuracy
- **Role-Based Access:**
    - **Admin Dashboard:** Manage users, view all loan applications, analytics
    - **Employee Dashboard:** Review, Approve/Reject loans
    - **User Dashboard:** Apply for loan & check eligibility instantly
- **Smart Features:** Real-time prediction, data visualization, secure authentication

### 🛠️ Tech Stack
- **Frontend:** Streamlit
- **ML Model:** XGBoost, Scikit-learn, Pandas
- **Database:** SQLite / CSV
- **Language:** Python
